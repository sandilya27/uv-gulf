# Repository working preferences

- Commit completed, verified changes without `Co-authored-by` trailers or other co-author attribution.
- After completing and verifying requested implementation work, commit and push directly to `main` by default. The user has authorized this workflow for this repository; do not ask for the same authorization again.
- Preserve unrelated user changes, never force-push, and report any verification or push failures accurately.
- Follow explicit task instructions when they override these defaults.
