# ProfileCard source

Adapted from React Bits ProfileCard, https://reactbits.dev/components/profile-card and https://reactbits.dev/r/ProfileCard-TS-CSS.json (17 October 2026).

The requested JS/Tailwind registry command requires shadcn configuration and Tailwind, which this project does not use. This is the equivalent official TypeScript/CSS source, customized for UV Gulf with local icons, descriptive portrait alt text, reduced-motion handling, native touch scrolling, navy framing, toned-down glare, and no social/status footer in TeamSection. Original license is preserved in LICENSE.md.
