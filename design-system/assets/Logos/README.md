# Logos

Supplied UV Gulf logo files, transparent PNG, trimmed to the artwork.

- `uvgulf-logo.png`: full-colour logo (navy `logo-navy` + sky `logo-sky`). Use on `surface`, `surface-alt`, `surface-raised`.
- `uvgulf-logo-reversed.png`: navy parts turned white, sky kept. Use on `surface-deep`, navy bands and photos.
- `uvgulf-mark.png`: the gear mark alone, full colour. Favicon, social avatar, chatbot avatar.
- `uvgulf-mark-reversed.png`: gear mark in white and sky for dark grounds.

Minimum width: 140px for the full logo, 32px for the mark. Clear space equals the height of the "U". A vector (SVG) master is still needed from UV Gulf for print and large sizes.
