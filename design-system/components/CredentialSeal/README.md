# CredentialSeal

Marks an accreditation or certification UV Gulf holds: an amber seal, the standard reference in mono, and a short label.

Provide `standard` exactly as written on the certificate (`ISO/IEC 17020:2012`, `ISO 9001:2015`) and an optional `label`. Show only credentials UV Gulf has supplied documentation for. Works on `surface` and inside `uvg-deep` bands.
