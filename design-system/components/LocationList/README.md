# LocationList

The head office and the cities UV Gulf serves, separated by sky-blue bars.

Defaults to Khobar as head office and Riyadh, Dammam, Jubail, Jeddah, Yanbu, Tabuk, Taif, Medina and Mecca. Override `cities` only with confirmed locations. Use it in the footer, on About and on Contact; it works on `surface` and inside `uvg-deep`.
