# MethodTag

A two-part tag for an NDT method: the standard code in mono on navy, then the method name.

Provide `code` (VT, UT, RT, ET, MT, AE, PT, LT) and `label` without the word "testing". Use on NDT pages, service cards and case studies to list the methods used. Always pair the code with a label the first time it appears on a page.
