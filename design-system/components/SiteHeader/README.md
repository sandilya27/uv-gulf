# SiteHeader

The global header: logo, main navigation, the Verify certificate shortcut and the enquiry button.

Provide `logoSrc` (full-colour logo) and `logoReversedSrc` (white-navy version), `current` for the active section, and `onDeep` when the header sits over the navy hero. Keep the nav order: Inspection, Training, Industries, About, Insights, Contact. Verify certificate stays visible at every width; below 1024px the nav collapses into a menu button.
