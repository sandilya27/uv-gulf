# Field

A labelled form control (text input, select or textarea) with an optional hint or error, used in the General, Inspection and Training enquiry forms.

Provide `label`, `as`, `name`, and for selects `options`. Mark required fields with `required`; the asterisk is added for you. Write errors as a fix: "Enter a full email address, like name@company.com". Set `mono` for certificate and reference numbers. Stack fields in one column on mobile, two on desktop.
