# CourseCard

A card for one training course: title, awarding body, summary and a short facts list.

Provide `title`, `summary`, and only the facts UV Gulf has confirmed: `body` (NEBOSH, IOSH, NASP, HACCP), `audience`, `duration`, `format`. Leave a fact out rather than guessing; "On request" is acceptable for duration. `href` goes to the course page, which carries the training enquiry form.
